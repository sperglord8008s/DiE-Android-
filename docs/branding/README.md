# GlassDigestor identity

GlassDigestor is the continuing project previously presented as DiE Android.
The name reflects whole-file digestion and transparent evidence. Detect It Easy /
CDiE remains a credited core engine; GlassDigestor is an independent application.
The repository URL, Java namespace and installed Android ID stay unchanged.

The mark combines a hexagonal lens, stacked file layers and one amber evidence
point. Mint `#59E1CA`, ice `#EAF5FA`, amber `#FFBC66` and dark `#101920` form the
palette. The mark is a generated original artwork, created with OpenAI image
generation during this project's development and selected by the maintainer.
It contains no third-party logo or external font. The supplied image is retained
unchanged in `app/src/main/res/drawable-nodpi/brand_mark.png`; Android's adaptive
icon supplies background and safe-area padding at runtime.

The project supplies this artwork under its GPL-3.0-only license. This statement
does not relicense upstream engines, databases or their marks. Keep their own
notices and attribution. Older tags, exported schema IDs and original license
notices retain their historical DiE Android names.
