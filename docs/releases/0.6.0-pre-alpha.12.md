# GlassDigestor 0.6.0-pre-alpha.12

This checkpoint concentrates on **the recovered files**. Gallerize now combines
PhotoRec and Binwalk in one Files view. Tap a file to preview it, or an archive
to browse its contents. Save individual files with proper extensions/MIME types,
or export every file in the selected group as an ordinary ZIP of actual
payloads across all gallery pages. Version code **18**.

Duplicate discoveries retain both engines' original findings. Nested files and
alternative reported lengths remain accessible. An engine failure does not hide
the other engine's files. Binwalk's separate 64 MiB limit remains explicit;
PhotoRec still accepts complete supported inputs up to 256 MiB. Unknown lengths
remain unknown and are not guessed from nearby headers or EOF. Full evidence,
manual ranges, grids and existing tools remain available.

All **180 host tests** pass, including direct preview, typed PNG saves and a
29-image/nested-payload ZIP surviving picker recreation. Real native discoveries
and independent byte/ZIP checks pass for JPEG, PNG, WAV, GIF, gzip, MP4 and
Unicode text. The fully written 80 MiB fixture checks a PNG and its exact typed
export beyond 64 MiB. Required generic/native checks, ARM64 assembly/lint and
APK signature/offline/notices/alignment verification pass. Five-job source CI passed on the exact source (run 44776359039); PR checks
passed (44776456230), and PR #14 merged as 0493c5b. Publisher run 44778247741
completed successfully. The seven existing x86 Android runtime lab contracts
also passed on source 123193d (44776359034). These do not verify full gallery/SAF
acceptance.

Platform decoder support remains format/device dependent. Complete PhotoRec
file checks, fragmented recovery, every media/document format, recursive archive
member galleries and production ARM64/SAF/handset acceptance remain incomplete.
See [file-gallery contracts](../recovered-file-gallery.md).
