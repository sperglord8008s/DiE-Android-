# GlassDigestor 0.6.0-pre-alpha.8

This checkpoint adds direct archive inspection and explicit byte-range viewing
to Gallerize cards. Android version code **14**; application ID and debug signing
configuration remain unchanged.

- Header-only cards have real actions: inspect their observed archive/compressed
  parsing tail, choose an inspection interval, view Hex or read the original
  witness. Unknown recovered sizes remain unknown.
- Decimal/hex offset and length select exact independently owned preview bytes.
  Origins retain the original associated finding and clearly distinguish the
  chosen interval from native recovered-file bounds. Grid-cell origins carry
  the same explicit meaning.
- Native archive launches retain complete gallery/card/witness context through
  restoration, scope changes, reports and selected-member origin exports.
  Gallery JSON headers/cards preserve exact UTF-16 using the shared writer.

Actual PhotoRec → gallery → libarchive tests decode an independently generated
embedded gzip and verify every decoded byte, complete context/origins, unchanged
null extents, source expiry/no-rescan restore and refusal/ownership boundaries.
The fully written 80 MiB-plus gallery fixture remains green. The complete
**170-case Android host suite** passes with zero failures/errors/skips, plus
required generic/native checks, ARM64 assembly/lint and fifteen-library APK
static verification. Source CI/publication are the next gates. See
[gallery range contracts](../gallery-inspection-ranges.md).

Real Android UID/Binder/SAF/media/PDF/process-death/16 KiB runtime acceptance,
arbitrary deobfuscation/passwords, exhaustive coverage, inherited cross-Activity
origins and full desktop parity remain incomplete/unverified. Offline ARM64/API
26+ debug-signed testing build; compare signer digests and keep the preceding APK.
