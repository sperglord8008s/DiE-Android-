# GlassDigestor 0.6.0-pre-alpha.2

This checkpoint adds checked recovered-content workflows to the
[0.6.0-pre-alpha.1 foundation](https://github.com/sperglord8008s/DiE-Android-/releases/tag/v0.6.0-pre-alpha.1).
The Android version code is **8**. The application ID and debug signing
configuration remain unchanged.

- Bounded Binwalk/PhotoRec findings open as independently owned previews, with
  the original parent SHA-256, byte range and candidate label. Exact recovery
  exports verify the complete captured parent before and after staging and use
  constrained engine/index/offset/format suggested names.
- Preview **Export bytes** preserves the exact captured payload through picker
  delay, source expiry and activity recreation. Cancellation and failed output
  clean the private stage; failures explicitly disclose possible partial data
  at the selected document-provider destination.
- A tool's captured whole input can enter Gallerize through a separate private
  handoff. The receiver validates ownership and byte identity, releases only
  its own eligible handoff and restores its capture without rescanning.
- Dense record views distinguish bold names, readable descriptions and exact
  monospace offsets/lengths. Details prioritize facts before full original
  record fields, with separately expandable mechanism explanations.

Four new API 28 host cases use real Binwalk/PhotoRec JNI and production
acquisition/widgets, substituting OS transport and document streams. The full
Android host suite passes **139 tests**, with zero failures/errors/skips.
Generic/native scanner, exact byte/cancellation/mutation ownership, the fully
written **80 MiB + 17 byte** gallery/grid fixture and SDK/tracker host contracts
pass. ARM64 assembly, lint and APK static signature/identity/offline/alignment
checks pass. The publisher separately requires all five source CI jobs before
promoting the exact APK and corresponding-source captures.

Unknown extents remain non-extractable. Format hints and previews do not prove
complete file integrity. Complete native reports/catalogs remain available;
persistent per-preview native-origin sidecars and cross-session investigation
history are pending. Broader libarchive/codecs are source/host/ARM64 core work;
the app's broader native archive worker/tree integration is still pending.

Actual handset, real SAF, isolated UID/Binder, codec/PDF, crash/process-death/
cache-pressure and 16 KiB Android runtime verification remain unverified.
Full desktop Detect It Easy parity is incomplete. See
[recovered-content contracts](../recovered-content.md),
[feature parity](../FEATURE-PARITY.md) and
[build versioning](../build-versioning.md).

Install the ARM64 **debug-signed testing APK** on Android API 26+. Keep the
checksums and original build manifest; compare the signer certificate before
updating an existing installation. Independent CI debug keys can differ.
Frontend GPL-3.0-only; upstream components retain their own licenses/notices.
No telemetry, INTERNET permission, automatic sample uploads or execution of
inspected applications.
