# GlassDigestor 0.6.0-pre-alpha.3

This development checkpoint adds the source-built native archive workbench to
pre-alpha.2's checked recovery/gallery workflows. Android version code **9**;
application ID and debug signing configuration remain unchanged.

- Content-identified virtual folders and complete native entry indices across
  supported archives/compressed streams; duplicate names remain selectable by
  index. Full returned metadata and raw accessor bytes remain available.
- Read-only input and separate empty output descriptors through the private
  isolated worker; whole-source SHA-256 guards, native metadata/size validation
  and independently checked derived member hashes.
- Nested archive Back/restoration, explicit intervals for embedded/prefixed
  archives, owned media/text/hex previews, byte export, member analysis and
  staged complete current-chain/failed-attempt report exports.
- The main Archive action accepts any captured input. Classic ZIP remains
  available. Complete pinned libarchive/codec notices and source headers are
  packaged with the additional native engine.

Core and model checks each cover 25 captures / 37 payload acquisitions, including
a 16 MiB + 17-byte member, 7z, RAR5, CAB, compressed ISO, TAR/PAX/xattrs/links,
duplicate ZIP names, CRC failures and supported compression frames. Five actual
native-engine host UI cases cover nested folders/Back/recreation, independent
preview/export, failures, explicit intervals and source mutation. Worker guards
include malformed/rejected payload descriptor closure. Main’s actual-CDiE
archive-action/member-result boundary is checked separately. The complete **147-case Android host suite**, ARM64 assembly, lint and static
APK checks pass with zero test failures/errors/skips. The APK packages fifteen
native libraries, complete archive notices and source identities. Source CI
and publication remain the next gates; a development version alone is not
a published checkpoint.

Format registration is not exhaustive subtype verification. Arbitrary
obfuscation, passwords, external volumes, fragmented recovery, per-preview
persistent native-origin sidecars and full history remain incomplete.
Actual device/API 26/API 35/UID/Binder/SAF/cancel/crash/media/PDF/cache-pressure
and 16 KiB runtime acceptance remain unverified. Full desktop DiE parity is
incomplete. See [archive contracts](../native-archives.md) and
[feature parity](../FEATURE-PARITY.md).

Debug-signed ARM64 testing build; compare signer digests before updates because
independent CI runners may use different debug keys. Preserve the preceding
checkpoint and reports. Offline application, no INTERNET permission or telemetry;
inspected applications are never installed or executed.
