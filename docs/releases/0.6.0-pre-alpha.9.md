# GlassDigestor 0.6.0-pre-alpha.9

This development checkpoint adds a separate Android worker runtime laboratory
and an API 26/35 emulator CI matrix. Android version code **15**; the production
application ID, ARM64 ABI and debug signing configuration remain unchanged.

The test-only x86_64 APK builds the unchanged production worker/client and real
hash/archive JNI. Its five checks cover isolated UID evidence, eight digests,
a fully written 16 MiB-plus independent hash oracle, embedded gzip extraction
through read/write descriptors, client alias refusal, token-scoped cancellation
under deterministic pipe backpressure and recovery after worker death.

Static verification checks the private isolated manifest against production,
source-copy equality, native architecture, signatures, versions, offline
permissions and retained notices. APK and source hashes accompany captured
runtime evidence. See the [laboratory contracts](../../runtime-worker/README.md).

Local test-APK compilation/static inspection, required generic/native checks,
25 archive captures/37 payloads, all **170 Android host tests**, production ARM64
assembly/lint and fifteen-library APK verification pass. **Actual emulator
execution and the five-job source CI gate remain pending.** Do
not describe the new runtime cases as verified until their actual jobs pass.
Production ARM64/handset/SAF/UI/media/PDF/16 KiB runtime acceptance and full
desktop parity remain incomplete/unverified. Earlier immutable published
checkpoints remain available.
