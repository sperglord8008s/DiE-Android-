# GlassDigestor 0.6.0-pre-alpha.5

This checkpoint makes large text files and complete rendered investigation
reports navigable. Android version code **11**; application ID and debug
signing configuration remain unchanged.

- UTF-8 and Hex previews provide First, Back/Previous, Next, Tail and byte-offset
  navigation with actual captured-input intervals. Text preserves complete
  characters across page seams and retains its last valid page on a bad jump.
- Automatic text recognition handles a bounded prefix ending inside a Unicode
  character. Preview recreation retains mode, text history and Hex position.
- Complete rendered JSON/smali/text reports are staged once and read in bounded
  pages. Source expiry does not change the capture; exports use the same complete
  bytes. Closing before the first page releases both staging and the busy state.

Independent UTF-8 fixtures reconstruct every byte across 161,892 pages and a
fully written 24,117,266-byte file. Five Android host cases cover the actual
snapshot/widget/navigation/export boundaries. The full **156-case Android host
suite** passes with zero failures/errors/skips, plus required generic/native
checks, ARM64 assembly/lint and fifteen-library APK static verification. Source
CI passed all five jobs in run `44661425550` and PR #7 merged. Publisher run `44664099702` succeeded; pre-alpha.5 is public
from exact CI source `37e7feea2ce3ede151cd5b29ccea499255f943e8`. See [text contracts](../text-paging.md).

Text decoding is UTF-8; automatic recognition and Tail validate bounded windows.
Selected-record fact dialogs retain their explicit display cap. The existing
256 MiB report-staging budget remains. Actual Android UID/Binder/SAF/media/PDF/
process-death and 16 KiB runtime acceptance, persistent per-preview native-origin
history and full desktop DiE parity remain incomplete/unverified. Debug-signed
ARM64/API 26+ testing build: compare signer digests before updates and keep the
preceding checkpoint. Offline application; no INTERNET permission or telemetry.
