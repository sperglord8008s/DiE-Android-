# GlassDigestor 0.6.0-pre-alpha.11

This development checkpoint links selected/captured APKs to exact-ID community
package descriptions while retaining the original observed evidence. Version
code **17**; production identity, ARM64 and signing configuration stay unchanged.

- Selected APK and per-source package-set actions use one original literal
  manifest package attribute, with whole APK/manifest identities and parser/
  signer/error context. Filenames and inventory guesses are not lookup IDs.
- Independent bounded association captures survive parent expiry and child
  recreation, accompany complete exports and retain every duplicate community
  claim. General catalog and complete original source exports remain available.
- A seventh real Android lab case now checks compiled-manifest worker parsing
  and package/SDK declarations against the installed trusted target.

Independent ownership/refusal/UTF-16/raw-number oracles and 18 focused host
cases pass, including three added actual AAPT2/signing/widget flows. All
**178 host tests**, required generic/native checks, ARM64 assembly/lint/APK
verification, the final parent-recreation check and test-APK compilation/static
checks pass. Five-job source CI and seven-case emulator execution are pending. ID association
is not verified publisher identity, behavior, device applicability or a removal
recommendation. See [contracts](../apk-community-context.md).
