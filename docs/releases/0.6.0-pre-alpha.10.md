# GlassDigestor 0.6.0-pre-alpha.10

This development checkpoint adds bounded video keyframes and media observations
to Gallerize's labeled audio/video cards. Version code **16**; production ARM64
identity/signing and previous checkpoints remain unchanged.

- Exact stored intervals reach Android through descriptors, with source SHA-256
  checked before/after. Unknown extents remain unknown and are not decoded.
- API 27+ requests bounded scaled keyframes; API 26 reports metadata and an
  explicit frame limitation. Codec failures retain available metadata.
- Card details expose transient source/API/interval/raw/null metadata/errors and
  frame request information, separate from the original native finding.
- A generated-video/audio case extends the real Android emulator laboratory;
  the original five worker contracts passed on API 26/35 at source `26ad7d6`.

The full **175-case Android host suite**, final frame-budget guard rerun,
required generic/native checks, ARM64 assembly/lint/fifteen-library APK checks
and runtime APK compilation/static verification pass. The five-job source CI
and new actual platform-codec runtime case remain pending. See
[media preview contracts](../gallery-media-previews.md). No full playback,
validity, production ARM64/handset/SAF/PDF/16 KiB runtime or desktop parity claim.
