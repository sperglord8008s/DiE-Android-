# GlassDigestor 0.6.0-pre-alpha.1

This numbered pre-release continues DiE Android as **GlassDigestor**, an offline
Android file, binary, media and system investigation workbench. Detect It Easy /
CDiE remains a credited core engine. The repository URL and Android application
ID (`org.diemobile`) remain unchanged. Android version code is **7**.

## Included workbench

- Gallerize maps discovered media, gap text, nested/overlapping headers, bounded
  stored ranges and unassigned bytes. Owned previews, complete source evidence,
  configurable byte/entropy grids and original-byte links remain available.
- File info puts observed format and identity first, combines reference material
  and provides individual/global expandable explanations. Tools are grouped by
  investigative purpose.
- Actual CDiE signatures and typed native structures, maps, entropy, imports,
  exports, resources and disassembly; all eight whole-file digests; grouped
  string classification; profiles, batches and exact byte/native-tree comparison.
- Actual Binwalk and PhotoRec header/data checks, libmpv codec/container probing,
  EXIF/XMP metadata, DEX/smali, compiled Android resources, APK signing evidence,
  base/split declarations, SDK and locally imported tracker rules.
- Nested ZIP/APK member browsing and checked handoffs into the gallery/preview.
  A source-built libarchive + bzip2/XZ/LZ4/Zstandard core is included in source
  and host fixtures; its broader Android archive browser is **not yet exposed**
  in this checkpoint.
- The GlassDigestor lens/layers logo, adaptive launcher icon and build details.
  Debug version names and APK filenames identify the numbered checkpoint,
  exact Git revision and any local changes.

## Downloads and verification

Use the **ARM64 debug APK** from this release. Keep the adjacent `.sha256`,
`build-manifest.txt`, checkpoint metadata and `SHA256SUMS`. The source revision
in those files is the authoritative build identity. Component source bundles
retain the pinned upstream sources and adapter/build instructions.

The release is published only after its five Android/host GitHub Actions jobs
pass. The Android host suite contains 135 tests at the preceding checkpoint;
these use real engines where the contracts describe them. Real Git-state
version/packaging cases additionally exercise clean, edited, ignored-output,
detached and unidentified source states. ARM64 compilation, lint, static APK
signature/identity/offline/16 KiB alignment checks and independent engine
fixtures are separate from actual handset verification.

No handset, real SAF picker, actual isolated UID/Binder transport, ARM64 media
playback or 16 KiB Android runtime verification is claimed. Full desktop DiE
parity and comprehensive hostile-input hardening remain incomplete. Read the
[feature-parity checklist](../FEATURE-PARITY.md) for exact scope and limitations.

## Installation and signing

Android 8.0 / API 26+ on ARM64 is required. These pre-release downloads are
explicitly **debug-signed testing builds**, using the existing debug signing
configuration. Separate CI runners may generate different keys. Compare the
signer certificate digest in the build manifest with your installed build;
a matching application ID alone does not make an update compatible. No
production release key has been introduced or substituted.

The earlier `v0.5.0-alpha` tag remains unchanged. Save reports and the previous
APK when testing a new build. The application has no INTERNET permission,
telemetry or automatic sample upload. Inspected files are never executed.
